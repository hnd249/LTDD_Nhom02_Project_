# 📱 TaxManager - Trợ lý Tài chính & Quản lý Thuế TNCN

Dự án cuối kỳ môn Lập trình di động - Nhóm 02.

## 👥 Thành viên nhóm
1. **Hồ Ngọc Đạt** (Leader) - UI Features & ViewModels
2. **Trần Hữu Đức** - Database & DI
3. **Nguyễn Thị Kim Nhung** - Domain & Utils
4. **Trần Quốc Đạt** - Base UI & Navigation

## 🚀 Tính năng chính
- Quản lý thu nhập và chi tiêu hàng ngày.
- Tự động tính toán thuế thu nhập cá nhân (TNCN) theo quy định mới nhất.
- Xuất báo cáo lịch sử giao dịch và bảng tính thuế ra file PDF.
- Thông báo nhắc nhở quản lý tài chính.

## 🛠 Công nghệ sử dụng
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Database:** Room Database
- **Dependency Injection:** Hilt
- **Architecture:** MVVM (Model-View-ViewModel)
